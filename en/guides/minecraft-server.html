Host a Minecraft server for your friends (port forwarding)

For friends outside your home to join a Minecraft server running on your PC, you need "port forwarding". Normally you do it in your router's settings page, but with Micle you can open and close ports with a single button.

If everyone is in the same home (same Wi-Fi), you don't need port forwarding. Just use the server PC's local address.

What you need

  • A Minecraft server (the official server.jar for Java, or Bedrock Dedicated Server)
  • Micle (free)
  • A router with UPnP turned on (most home routers have it on by default)

How to do it

  1. Start the server and check you can join

    Start the server and make sure you can join from Minecraft on the same PC using localhost. If that fails, fix the server first.

  2. Open "Network" in Micle

    Open Other → Network in Micle's left menu and press "Find router". When it says "Found", you are ready.

  3. Pick Minecraft from common games

    From "Add from common games…", choose Minecraft (Java) = port 25565 TCP or Minecraft (Bedrock) = port 19132 UDP. The name and port are filled in for you.

  4. Press "Open"

    When it shows "Open", the port is forwarded. If friends still can't join, also turn on "Allow" in the Firewall column (Windows asks once).

  5. Send your address to friends

    Press "Copy" next to External IP in the Addresses card, and send it with the port number, e.g. 203.0.113.5:25565. Friends enter it in Multiplayer → Direct Connection.

  6. Close it when you are done

    Don't leave ports open. Turn on "Close when Micle closes" and they close automatically.

Troubleshooting

  • Router not found: UPnP may be off in your router. Turn on "UPnP" following your router's manual.
  • Open but friends can't join: Some internet plans don't allow incoming connections (CGNAT, IPv6-only, etc.). Consider a static IP option from your provider or a service like Minecraft Realms.
  • "Port already in use" and the server won't start: Use "Apps using a port" in Micle to see which app is using it.
Port forwarding lets outside people reach your PC. Use a whitelist on your server, keep it updated, and close the port when you are done.

FAQ

Is port forwarding dangerous?

Only the software running on that port (your Minecraft server) is reachable. Using a whitelist and closing the port afterwards greatly reduces the risk.

Does my IP address change?

Depending on your plan, it can change, for example when the router restarts. If friends can't join, check "External IP" in Micle again.

Can Bedrock players (phones) join?

If you open a Bedrock server (port 19132 UDP), Bedrock players on phones and PCs can join. Consoles like Switch have restrictions on external servers.

Micle is free to use

Besides port forwarding, Micle also checks firewall rules, apps using a port, and your connection speed.
