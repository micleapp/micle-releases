Get started with Morse code (send, decode, practice)

Micle turns keyboard keys or mouse buttons into a Morse key. What you key is shown as text and can be sent into Discord and other calls as Morse tones. It can also decode incoming Morse and has a listening practice mode.

What you need

  • Micle (free)
  • For calls, Discord or similar set up (see here)

How to do it

  1. Choose how you key

    On the Morse page, Keys tab, choose a straight key (one key, length decides dot or dash) or a paddle (separate keys for dot and dash: Iambic A, Iambic B or Ultimatic), and assign keys or mouse buttons.

  2. Set speed and tone

    In the Tone & Speed tab, set character speed (WPM) and pitch. 12–15 WPM is a good start. "Slower spacing only (Farnsworth)" keeps character speed but adds space between characters.

  3. Try keying

    Key with your assigned keys: the timeline shows the lengths and "Decoding my keying" shows the text.

  4. Type text to send

    Type in the Send tab and it is converted to Morse automatically. Prosigns like <AR> and Japanese kana work too. Save common messages as macros and send them with Ctrl + Alt + 1–8.

  5. Practice listening

    The Practice tab plays random Morse for you to answer. Per-character accuracy is shown in color, and weak characters can appear more often.

Decode other people's Morse

The Receive tab listens for Morse in the call audio and turns it into text. If noise causes false hits, raise "Detection strictness".

You can even send silent signals in Morse while gaming.

FAQ

Does it support Japanese (Wabun) Morse?

Yes. Both sending and decoding can switch between international (A–Z) and Japanese kana.

Can I use a real Morse key?

If the device shows up as a keyboard or mouse input, assign that key and use it.
