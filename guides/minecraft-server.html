Micle の使い方ガイド

マイクラのサーバーを、友だちに公開する（ポート開放）

自分の PC で立てたマインクラフトのサーバーに、家の外の友だちが入るには「ポート開放」が必要です。ふつうはルーターの設定画面に入って操作しますが、Micle を使うとボタンひとつで開けたり閉じたりできます。

同じ家（同じ Wi-Fi）の人だけで遊ぶなら、ポート開放はいりません。サーバーの PC の「家の中のアドレス」で入れます。

用意するもの

  • マイクラのサーバー（Java 版は公式の server.jar、統合版は Bedrock Dedicated Server など）
  • Micle（無料）
  • UPnP が ON になっているルーター（多くの家庭用ルーターは、はじめから ON です）

やり方

  1. サーバーを立てて、自分で入れることを確かめる

    まずはサーバーを起動して、同じ PC のマイクラから localhost で入れることを確かめます。ここで入れない時は、ポート開放の前にサーバーの設定を見直します。

  2. Micle の「ネット」を開く

    Micle の左のメニューの「その他」→「ネット」を開き、「ルーターを探す」を押します。「見つかりました」と出れば準備完了です。

  3. よく使うゲームから「Minecraft」を選ぶ

    「よく使うゲームから足す…」で、Java 版なら Minecraft（Java 版）＝ 25565 番・TCP、統合版なら Minecraft（統合版）＝ 19132 番・UDP を選びます。名前とポートが自動で入ります。

  4. 「開ける」を押す

    「開いています」になれば、ポート開放はできています。うまくいかない時は、同じ行の「ファイアウォール」の「受け入れる」も ON にします（Windows の確認が 1 回出ます）。

  5. 友だちにアドレスを教える

    「アドレス」の欄にある 外から見た IP の横の「コピー」を押し、ポート番号と一緒に友だちに送ります。例：203.0.113.5:25565。友だちはマイクラの「マルチプレイ」→「サーバーに直接接続」に入れるだけです。

  6. 遊び終わったら閉じる

    開いたままにしないのが安全です。「Micle を閉じたら閉じる」を ON にしておけば、Micle を終えた時に自動で閉じます。

うまくいかない時

  • ルーターが見つからない：ルーターの設定で UPnP が OFF になっていることがあります。ルーターの説明書で「UPnP」を ON にしてください。
  • 開いているのに入れない：家のネットの契約によっては、外から入れない仕組み（CGNAT・IPv6 だけの接続など）のことがあります。その場合は、プロバイダーの固定 IP のサービスや、Minecraft Realms などの方法を検討してください。
  • 「ポートが使われています」と出てサーバーが起動しない：Micle の「ポートを使っているアプリ」で、どのアプリが使っているか調べられます。
ポート開放は、外の人があなたの PC に届くようにする設定です。サーバーはホワイトリストを使う、最新のバージョンにしておく、使い終わったら閉じる、を守りましょう。

よくある質問

ポート開放は危なくないですか？

開けたポートで動くソフト（マイクラのサーバー）にだけ届きます。ホワイトリストを使い、使い終わったら閉じれば、危険はぐっと減らせます。

IP アドレスは毎回同じですか？

家のネットの契約によっては、ルーターを入れ直した時などに変わります。友だちが入れなくなったら、Micle で「外から見た IP」をもう一度確かめてください。

統合版（スマホ・Switch）の友だちも入れますか？

統合版のサーバー（19132 番・UDP）を開けば、スマホや PC の統合版から入れます。Switch などのゲーム機は、外部サーバーへの接続に制限があります。

Micle は無料で使えます

ポート開放のほかにも、ファイアウォールの受け入れ・ポートを使っているアプリ・つながりの速さを、Micle ひとつで確かめられます。
