使い方ガイド

Micle を使った、よくある使い方を手順つきでまとめました。どれも無料版でできます（プロ版の機能には印を付けています）。

マイクラのサーバーを友だちに公開する

ルーターの設定画面を開かずに、ボタンでポート開放。外から入るためのアドレスもすぐ分かります。

くわしく見る →

Discord でボイスチェンジする

無料の仮想マイクと Micle で、Discord の通話の声を変える手順。プリセット 24 種類。

くわしく見る →

通話のノイズを消す

キーボードの音・ファン・生活音を AI で消して、声だけを届ける設定。

くわしく見る →

モールス信号を始める

文字をモールス音で送る・相手のモールスを文字にする・聞き取りの練習。和文にも対応。

くわしく見る →

配信に立ち絵・字幕・曲名を出す

ゲームの上に、しゃべると動く立ち絵・字幕・再生中の曲・タイマーを重ねる。

くわしく見る →

ゲーム中に便利な小技

クイックメニュー・後ろのウィンドウを別モニターへ・照準・メモ・GIF 録画など。

くわしく見る →

ほかにも、こんな使い方があります

  • 通話で効果音 — キー 1 つで効果音を鳴らし、相手にも聞かせる
  • BGM を流しながら雑談 — 話している間だけ BGM を自動で小さく
  • 通話の議事録 — 話した内容を PC の中だけで文字にして、要約も
  • みんなでサイコロ・くじ・投票 — 画面共有で見せながら遊べる遊び道具
  • 画面に書き込んで説明 — ゲームや資料の上にペンで書き込む
  • ゲームの文字をその場で翻訳 — 海外のゲームの文字を読んで訳を重ねる（プロ版）

Micle は無料で使えます

通話・ゲーム・配信を補助する機能を、ひとつにまとめた Windows アプリです。基本の機能はずっと無料で、広告もありません。

無料でダウンロード

Windows 10 / 11（64bit）・最新バージョン v・ MB・広告なし
