Micle の使い方ガイド

モールス信号を始める（送る・聞き取る・練習する）

Micle では、キーボードやマウスのボタンを電鍵（モールスのキー）にして打てます。打ったモールスは文字にして表示され、Discord などの通話にモールス音として流せます。相手のモールスを聞き取って文字にする機能や、聞き取りの練習もあります。

用意するもの

  • Micle（無料）
  • 通話で使う時は、Discord などの設定（こちら）

やり方

  1. 打ち方を選ぶ

    「モールス」のページの「キー」タブで、手動キー（1 つのキーで長さを打ち分ける）か、エレキー（短点と長点を別のキーで打つ。A・B・ウルティマから選べます）を選び、使うキーやマウスのボタンを割り当てます。

  2. 速さと音を決める

    「音・速度」タブで、文字の速さ（WPM）と音の高さを決めます。はじめは 12〜15 WPM くらいがおすすめです。「間隔だけゆっくり（ファーンズワース）」を使うと、文字の速さはそのままで、文字の間だけを広げられます。

  3. 打ってみる

    割り当てたキーで打つと、タイムラインに長さが出て、「自分の打鍵を解読」に文字が出ます。

  4. 文字を打って送る

    「送信」タブに文字を打つと、自動でモールス音に変えて送ります。<AR> などの略符号や、和文（カナ）も使えます。よく使う文は定型文にして、Ctrl + Alt + 1〜8 で送れます。

  5. 聞き取りの練習をする

    「練習」タブでは、ランダムに流れるモールスを聞き取って答えます。文字ごとの正解率が色で分かり、苦手な文字を多めに出すこともできます。

相手のモールスを文字にする

「受信」タブで、相手の声（通話の音）に混ざったモールスを聞き取って、文字にします。雑音で誤反応する時は「判定の厳しさ」を上げます。

ゲーム中に、声を出さずにモールスで合図を送る、という遊び方もできます。

よくある質問

和文モールスは使えますか？

はい。送信・解読ともに、欧文（A-Z）と和文（カナ）を切り替えられます。

本物の電鍵は使えますか？

キーボードやマウスとして入力される機器なら、そのキーを割り当てて使えます。

Micle は無料で使えます

通話・ゲーム・配信を補助する機能を、ひとつにまとめた Windows アプリです。基本の機能はずっと無料で、広告もありません。

無料でダウンロード

Windows 10 / 11（64bit）・最新バージョン v・ MB・広告なし
