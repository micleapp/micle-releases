Discord でボイスチェンジする方法

Micle で変えた声を Discord に届けるには、「仮想マイク」を使います。Micle が仮想マイクに声を流し、Discord はその仮想マイクをマイクとして使う、という形です。設定は最初に 1 回だけです。

用意するもの

  • Micle（無料）
  • VB-CABLE（VB-Audio Software の無料の仮想マイク。Micle の中から入れられます）
  • Discord（PC 版）

やり方

  1. VB-CABLE を入れる

    Micle の 設定 → 機器 の「VB-CABLE」で「ダウンロードして入れる」を押します。公式の配布元からダウンロードし、入れる画面が出るので「Install Driver」を押し、最後に PC を再起動します。

  2. Micle の送信先を確かめる

    再起動後、Micle の 設定 → 機器 の「送信先」が CABLE Input になっていることを確かめます（見つかれば自動で選ばれます）。

  3. Discord の入力デバイスを変える

    Discord の ユーザー設定 → 音声・ビデオ → 入力デバイス で「CABLE Output (VB-Audio Virtual Cable)」を選びます。

    同じ画面で、Discord のノイズ抑制・エコー除去・自動ゲイン調整を OFF にし、入力感度の自動調整も OFF にして低めにします（ON のままだと、効果音や演奏が消されたり、声がこもったりします）。マイク入力は Micle が混ぜて送るので、Discord でマイクを選び直す必要はありません。

  4. 声を選ぶ

    Micle の「ボイスチェンジ」で、プリセット（女の子・男・子ども・ロボット・電話・ラジオ など 24 種類）を選び、「ボイチェン」を ON にします。高さ・響き・エフェクトで細かく調整できます。

  5. 相手にどう聞こえるか確かめる

    「その他」→「テスト」の「相手にどう聞こえるか」で、5 秒録って聞き返せます。通話の前に一度確かめておくと安心です。

もっと便利に

  • キーで切り替え：ボイチェンキーを決めておくと、タップで ON/OFF、押しながらホイールで声の高さを変えられます。
  • 自作の声：調整した声を「今の声を保存」で保存し、キー 1 つで呼び出せます。
  • ノイズ除去と一緒に：AI ノイズ除去と自動音量を一緒に使うと、変えた声も聞き取りやすくなります。
声を変えて他人になりすますことや、嫌がらせに使うことはやめましょう。

よくある質問

相手に声が届きません

Discord の入力デバイスが「CABLE Output」になっているか、Micle の「オンエア」が ON か確かめてください。Micle の「テスト」のページで、まとめて確かめられます。

自分の変わった声を聞きたい

ボイスチェンジの「自分の声を聞く」を上げると、ヘッドホンで加工後の声を確かめられます。

Discord 以外でも使えますか？

はい。マイクを選べるアプリ（ゲームのボイスチャット・Zoom・Teams・OBS など）なら、マイクに「CABLE Output」を選べば使えます。

Micle は無料で使えます

通話・ゲーム・配信を補助する機能を、ひとつにまとめた Windows アプリです。基本の機能はずっと無料で、広告もありません。
