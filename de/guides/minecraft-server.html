Minecraft-Server für deine Freunde öffnen (Portfreigabe)

Damit Freunde außerhalb deines Zuhauses einem Minecraft-Server auf deinem PC beitreten können, brauchst du eine „Portfreigabe“ (Port Forwarding). Normalerweise geht das über die Einstellungsseite des Routers – mit Micle öffnest und schließt du Ports mit einem Knopf.

Wenn alle im selben Zuhause (gleiches WLAN) sind, brauchst du keine Portfreigabe. Nutzt einfach die lokale Adresse des Server-PCs.

Was du brauchst

  • Ein Minecraft-Server (die offizielle server.jar für Java oder Bedrock Dedicated Server)
  • Micle (kostenlos)
  • Ein Router mit aktiviertem UPnP (bei den meisten Heimroutern ab Werk an)

So geht's

  1. Server starten und selbst beitreten

    Starte den Server und prüfe, ob du ihm auf demselben PC über localhost beitreten kannst. Wenn nicht, behebe zuerst das Server-Problem.

  2. In Micle „Network“ öffnen

    Öffne im linken Menü von Micle Other → Network und drücke „Find router“. Steht dort „Found“, bist du bereit.

  3. Minecraft aus den gängigen Spielen wählen

    Wähle unter „Add from common games…“ Minecraft (Java) = Port 25565 TCP oder Minecraft (Bedrock) = Port 19132 UDP. Name und Port werden automatisch eingetragen.

  4. „Open“ drücken

    Zeigt es „Open“ an, ist der Port freigegeben. Kommen Freunde trotzdem nicht rein, aktiviere auch „Allow“ in der Spalte Firewall (Windows fragt einmal nach).

  5. Adresse an Freunde schicken

    Drücke „Copy“ neben External IP in der Karte Addresses und sende sie mit der Portnummer, z. B. 203.0.113.5:25565. Freunde geben sie unter Mehrspieler → Direktverbindung ein.

  6. Danach wieder schließen

    Lass Ports nicht offen. Mit „Close when Micle closes“ werden sie beim Beenden von Micle automatisch geschlossen.

Wenn es nicht klappt

  • Router wird nicht gefunden: UPnP ist im Router evtl. aus. Aktiviere „UPnP“ laut Router-Handbuch.
  • Offen, aber niemand kommt rein: Manche Internettarife erlauben keine eingehenden Verbindungen (CGNAT, nur IPv6 usw.). Erwäge eine feste IP beim Anbieter oder einen Dienst wie Minecraft Realms.
  • „Port wird bereits verwendet“, Server startet nicht: Mit „Apps using a port“ in Micle siehst du, welche App ihn nutzt.
Portfreigabe macht deinen PC von außen erreichbar. Nutze eine Whitelist, halte den Server aktuell und schließe den Port danach.

Häufige Fragen

Ist Portfreigabe gefährlich?

Erreichbar ist nur die Software auf diesem Port (dein Minecraft-Server). Mit Whitelist und Schließen des Ports danach sinkt das Risiko stark.

Ändert sich meine IP-Adresse?

Je nach Tarif kann sie sich ändern, etwa nach einem Router-Neustart. Wenn Freunde nicht mehr reinkommen, prüfe „External IP“ in Micle erneut.

Können Freunde mit Bedrock (Handy) beitreten?

Wenn du einen Bedrock-Server öffnest (Port 19132 UDP), können Bedrock-Spieler auf Handy und PC beitreten. Konsolen wie die Switch haben Einschränkungen bei externen Servern.

Micle ist kostenlos

Neben der Portfreigabe prüft Micle auch Firewall-Regeln, Apps auf einem Port und deine Verbindungsgeschwindigkeit.
