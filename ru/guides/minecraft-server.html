Откройте сервер Minecraft для друзей (проброс портов)

Чтобы друзья не из вашего дома могли зайти на сервер Minecraft на вашем ПК, нужен «проброс портов» (port forwarding). Обычно это делается в настройках роутера, но в Micle порты открываются и закрываются одной кнопкой.

Если все находятся в одном доме (одна сеть Wi-Fi), проброс портов не нужен — используйте локальный адрес ПК с сервером.

Что понадобится

  • Сервер Minecraft (официальный server.jar для Java или Bedrock Dedicated Server)
  • Micle (бесплатно)
  • Роутер с включённым UPnP (у большинства домашних роутеров включён по умолчанию)

Как это сделать

  1. Запустите сервер и проверьте вход

    Запустите сервер и убедитесь, что можете зайти из Minecraft на том же ПК через localhost. Если нет — сначала исправьте сервер.

  2. Откройте «Network» в Micle

    Откройте Other → Network в меню слева и нажмите «Find router». Когда появится «Found», всё готово.

  3. Выберите Minecraft из популярных игр

    В «Add from common games…» выберите Minecraft (Java) = порт 25565 TCP или Minecraft (Bedrock) = порт 19132 UDP. Название и порт подставятся сами.

  4. Нажмите «Open»

    Когда появится «Open», порт проброшен. Если друзья всё ещё не могут зайти, включите и «Allow» в столбце Firewall (Windows спросит один раз).

  5. Отправьте адрес друзьям

    Нажмите «Copy» рядом с External IP в карточке Addresses и отправьте вместе с номером порта, например 203.0.113.5:25565. Друзья вводят его в «Сетевая игра» → «Прямое подключение».

  6. Закройте после игры

    Не оставляйте порты открытыми. Включите «Close when Micle closes» — они закроются сами при выходе из Micle.

Если не получается

  • Роутер не найден: возможно, UPnP выключен. Включите «UPnP» по инструкции к роутеру.
  • Порт открыт, но друзья не заходят: некоторые тарифы не пропускают входящие соединения (CGNAT, только IPv6 и т. п.). Рассмотрите статический IP у провайдера или сервис вроде Minecraft Realms.
  • «Порт уже используется», сервер не запускается: в Micle «Apps using a port» покажет, какое приложение его занимает.
Проброс портов делает ваш ПК доступным извне. Используйте белый список на сервере, обновляйте его и закрывайте порт после игры.

Частые вопросы

Проброс портов опасен?

Доступна только программа на этом порту (ваш сервер Minecraft). С белым списком и закрытием порта после игры риск сильно снижается.

Мой IP-адрес меняется?

В зависимости от тарифа может меняться, например после перезагрузки роутера. Если друзья не могут зайти, снова проверьте «External IP» в Micle.

Смогут ли зайти друзья на Bedrock (телефон)?

Если открыть сервер Bedrock (порт 19132 UDP), зайти смогут игроки Bedrock на телефонах и ПК. У консолей вроде Switch есть ограничения на внешние серверы.
