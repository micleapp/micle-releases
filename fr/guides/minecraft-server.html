Ouvrez votre serveur Minecraft à vos amis (ouverture de ports)

Pour que des amis hors de chez vous rejoignent un serveur Minecraft qui tourne sur votre PC, il faut une « redirection de ports ». D'habitude, cela se fait dans la page de configuration de la box, mais avec Micle, un seul bouton suffit pour ouvrir et fermer les ports.

Si tout le monde est dans la même maison (même Wi-Fi), pas besoin d'ouvrir de ports : utilisez l'adresse locale du PC serveur.

Ce qu'il vous faut

  • Un serveur Minecraft (le server.jar officiel pour Java, ou Bedrock Dedicated Server)
  • Micle (gratuit)
  • Une box ou un routeur avec l'UPnP activé (c'est le cas par défaut sur la plupart)

Étapes

  1. Lancez le serveur et vérifiez que vous pouvez vous connecter

    Lancez le serveur et vérifiez que vous pouvez le rejoindre depuis Minecraft sur le même PC avec localhost. Sinon, corrigez d'abord le serveur.

  2. Ouvrez « Network » dans Micle

    Ouvrez Other → Network dans le menu de gauche de Micle et appuyez sur « Find router ». Quand « Found » s'affiche, tout est prêt.

  3. Choisissez Minecraft dans les jeux courants

    Dans « Add from common games… », choisissez Minecraft (Java) = port 25565 TCP ou Minecraft (Bedrock) = port 19132 UDP. Le nom et le port se remplissent tout seuls.

  4. Appuyez sur « Open »

    Quand « Open » s'affiche, le port est ouvert. Si vos amis ne peuvent toujours pas entrer, activez aussi « Allow » dans la colonne Firewall (Windows demande une fois).

  5. Envoyez votre adresse à vos amis

    Appuyez sur « Copy » à côté de External IP dans la carte Addresses et envoyez-la avec le numéro de port, par ex. 203.0.113.5:25565. Vos amis la saisissent dans Multijoueur → Connexion directe.

  6. Fermez à la fin

    Ne laissez pas les ports ouverts. Activez « Close when Micle closes » pour qu'ils se ferment automatiquement à la fermeture de Micle.

En cas de problème

  • Box introuvable : l'UPnP est peut-être désactivé. Activez-le en suivant le manuel de votre box.
  • Ouvert mais vos amis n'entrent pas : certains abonnements bloquent les connexions entrantes (CGNAT, IPv6 seulement, etc.). Pensez à une IP fixe chez votre fournisseur ou à un service comme Minecraft Realms.
  • « Port déjà utilisé » et le serveur ne démarre pas : « Apps using a port » dans Micle indique quelle appli l'utilise.
Ouvrir des ports permet à des personnes extérieures d'atteindre votre PC. Utilisez une liste blanche, gardez le serveur à jour et fermez le port à la fin.

Questions fréquentes

Ouvrir des ports, est-ce dangereux ?

Seul le logiciel qui utilise ce port (votre serveur Minecraft) est accessible. Avec une liste blanche et en fermant le port ensuite, le risque baisse fortement.

Mon adresse IP change-t-elle ?

Selon votre abonnement, elle peut changer, par exemple au redémarrage de la box. Si vos amis ne peuvent plus entrer, revérifiez « External IP » dans Micle.

Les amis sur Bedrock (mobile) peuvent-ils entrer ?

Si vous ouvrez un serveur Bedrock (port 19132 UDP), les joueurs Bedrock sur mobile et PC peuvent entrer. Les consoles comme la Switch ont des restrictions sur les serveurs externes.

Micle est gratuit

En plus de l'ouverture de ports, Micle vérifie les règles du pare-feu, les applis qui utilisent un port et la vitesse de votre connexion.
