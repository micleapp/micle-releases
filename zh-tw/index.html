想要的功能，全都有。

Micle 是一款從旁輔助語音通話、遊戲和直播的 Windows 應用程式。變聲、降噪、音效、在遊戲上顯示立繪和字幕、一鍵快捷鍵、Minecraft 連接埠轉送、筆記，全部集中在一個應用程式裡。基本功能永久免費，沒有廣告。

功能

全部在一個應用程式裡。不用的功能關掉後，畫面和背景處理都會消失，輕快又清爽。

變聲器

自由調整音高、共鳴和效果。女生、機器人、電話、山洞等 24 種預設，可直接用於 Discord 等語音通話。

AI 降噪・自動音量

去除鍵盤、風扇和生活噪音，只傳遞人聲。也會把忽大忽小的聲音調整到合適音量。

音效・BGM・朗讀

一個鍵播放音效。把喜歡的音樂當作 BGM 放進通話，說話時自動調小。

疊加顯示（立繪・字幕・歌名）

在遊戲畫面上顯示立繪、時鐘、計時器、正在播放的歌曲和字幕，也能出現在直播中。

快速選單

長按或連按某個鍵，遊戲中也能馬上叫出的小面板。可放音量、裝置電量、開關和筆記。

快捷鍵・巨集

一鍵開啟應用程式、移動視窗、調整音量和亮度、轉換文字等 99 種操作。也能錄製並重播操作的巨集。

把視窗移到另一台螢幕

不用關閉全螢幕遊戲，就能把遊戲後面的視窗移到旁邊的螢幕。

連接埠轉送・網路

不用打開路由器設定頁，一個按鈕就能為 Minecraft 等伺服器開放連接埠。也能檢查防火牆和網速。

筆記・待辦清單

隨手寫、馬上看的筆記。支援待辦清單、標籤、釘選和到期提醒。

演奏

鍵盤變鋼琴。用鼓、伴奏和循環錄音，在通話裡一起合奏。

摩斯電碼

把輸入的文字變成摩斯音傳送，也能把對方的摩斯電碼辨識成文字。也可以練習。

會議記錄（語音轉文字）

只在你的電腦裡把通話轉成文字，聲音不會傳到網路上。

小遊戲・白板

骰子、輪盤、抽籤、投票、搶答、賓果，以及可以直接在螢幕上畫的筆。

視窗翻譯 PRO

讀取遊戲和應用程式裡的文字，當場翻譯並疊加顯示。只在電腦裡執行。

AI 畫圖・製作立繪 PRO

用文字描述就能產生圖片，還能做出張嘴、眨眼和不同表情。也能做動圖。

直播畫面・虛擬攝影機 PRO

把立繪、視窗和攝影機疊在一起，當作 Discord 攝影機或畫面分享顯示。

FAQ

出現「Windows 已保護您的電腦」

Micle 仍是預先發行版，在 Windows 將它認定為常用應用程式之前，可能會出現這個藍色畫面。按「其他資訊」→「仍要執行」即可開啟。請只從官方頁面（GitHub）下載。

怎麼在 Discord 中使用？

安裝免費的虛擬麥克風「VB-CABLE」（VB-Audio Software 的捐贈軟體，另行發佈），並把 Discord 的輸入裝置設為「CABLE Output」。Micle 第一次啟動時會依畫面一步步引導。詳見 在 Discord 中使用變聲器。

免費版有期限或廣告嗎？

沒有。免費版永久免費，也不會顯示廣告。最初 3 天也可以試用專業版功能。不用的功能可以隱藏。

會讓遊戲變卡嗎？

關閉不用的功能後，相應處理也會停止。也有輕量模式。AI 功能的資料只在使用時才下載。

需要安裝嗎？

不需要。開啟下載的 Micle.exe 就能使用。想顯示在開始功能表的話，也可以在應用程式內安裝到電腦（不需要系統管理員權限）。

我的聲音會被傳到別處嗎？

不會。變聲、降噪、轉文字和 AI 都在你的電腦裡執行。詳見 隱私權政策。

怎麼開通專業版？

把購買郵件中的授權金鑰貼到 Micle 的 Settings → About → License key，然後按「Unlock」。只有第一次驗證需要連網。
