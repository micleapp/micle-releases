Micle 使用教學

開始使用摩斯電碼（傳送・辨識・練習）

Micle 可以把鍵盤按鍵或滑鼠按鈕當作電鍵使用。拍發的電碼會顯示為文字，也能以摩斯音的形式送進 Discord 等通話。也可以辨識對方的摩斯電碼，並提供抄收練習。

需要準備

  • Micle（免費）
  • 在通話中使用時，需要設定 Discord 等（請參考這裡）

操作步驟

  1. 選擇拍發方式

    在 Morse 頁面的 Keys 分頁中，選擇 手鍵（一個鍵，以按壓長短區分點劃）或 自動鍵（點和劃用不同的鍵），並指派按鍵或滑鼠按鈕。

  2. 設定速度和音調

    在 Tone & Speed 分頁中設定字元速度（WPM）和音高。建議從 12–15 WPM 開始。「Slower spacing only (Farnsworth)」可以在保持字元速度的同時加大字元間隔。

  3. 試著拍發

    用指派的鍵拍發，時間軸會顯示長短，「Decoding my keying」會顯示文字。

  4. 輸入文字傳送

    在 Send 分頁輸入文字，會自動轉換成摩斯音傳送。也支援 <AR> 等勤務符號。常用語可以存成固定句，用 Ctrl + Alt + 1–8 傳送。

  5. 練習抄收

    Practice 分頁會隨機播放摩斯電碼讓你作答。每個字元的正確率會以顏色顯示，也能讓不熟的字元多出現。

把對方的摩斯電碼變成文字

Receive 分頁會監聽通話聲音中的摩斯電碼並轉成文字。雜音造成誤判時，請調高「Detection strictness」。

遊戲中也可以不出聲，用摩斯電碼偷偷打信號。

常見問題

支援日文摩斯電碼嗎？

支援。傳送和辨識都可以在國際碼（A–Z）和日文假名之間切換。

可以用真正的電鍵嗎？

只要裝置是以鍵盤或滑鼠輸入的形式辨識，就能指派那個鍵來使用。

Micle 可以免費使用

把輔助語音通話、遊戲和直播的功能集中在一個 Windows 應用程式裡。基本功能永久免費，沒有廣告。
