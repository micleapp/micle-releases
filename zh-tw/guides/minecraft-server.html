把 Minecraft 伺服器開放給朋友（連接埠轉送）

想讓家外面的朋友加入你電腦上的 Minecraft 伺服器，需要「連接埠轉送（Port Forwarding）」。一般要進入路由器設定頁操作，而用 Micle 只要一個按鈕就能開放或關閉連接埠。

如果大家都在同一個家裡（同一個 Wi-Fi），就不需要連接埠轉送，用伺服器電腦的區域網路位址即可加入。

需要準備

  • Minecraft 伺服器（Java 版用官方 server.jar，基岩版用 Bedrock Dedicated Server 等）
  • Micle（免費）
  • 已開啟 UPnP 的路由器（多數家用路由器預設開啟）

操作步驟

  1. 啟動伺服器並確認自己能進入

    先啟動伺服器，用同一台電腦上的 Minecraft 透過 localhost 確認能進入。如果這裡進不去，請先檢查伺服器設定。

  2. 打開 Micle 的「Network」

    在 Micle 左側選單中打開 Other → Network，按「Find router」。顯示「Found」就準備好了。

  3. 從常用遊戲中選擇 Minecraft

    在「Add from common games…」中，Java 版選 Minecraft (Java) = 25565 連接埠・TCP，基岩版選 Minecraft (Bedrock) = 19132 連接埠・UDP。名稱和連接埠會自動填入。

  4. 按「Open」

    顯示「Open」就表示連接埠已開放。如果仍然無法連線，把同一列防火牆欄的「Allow」也打開（Windows 會確認一次）。

  5. 把位址告訴朋友

    在「Addresses」欄中按 External IP 旁的「Copy」，連同連接埠號碼一起傳給朋友，例如 203.0.113.5:25565。朋友在 Minecraft 的「多人遊戲」→「直接連線」中輸入即可。

  6. 玩完後關閉

    不要一直開著比較安全。打開「Close when Micle closes」，關閉 Micle 時會自動關閉。

遇到問題時

  • 找不到路由器：路由器的 UPnP 可能被關閉了。請參照路由器說明書開啟「UPnP」。
  • 已開放但朋友進不來：部分網路方案不允許外部連線（CGNAT、僅 IPv6 等）。可以考慮電信業者的固定 IP 服務，或 Minecraft Realms 等方式。
  • 出現「連接埠已被使用」，伺服器無法啟動：用 Micle 的「Apps using a port」查看是哪個應用程式在使用。
連接埠轉送會讓外部的人能連到你的電腦。請為伺服器啟用白名單、保持最新版本，用完後關閉連接埠。

常見問題

連接埠轉送危險嗎？

外部只能連到在該連接埠執行的軟體（Minecraft 伺服器）。啟用白名單並在用完後關閉，可以大幅降低風險。

IP 位址每次都一樣嗎？

取決於你的網路方案，重新啟動路由器等情況下可能會變。朋友進不來時，請在 Micle 重新確認「External IP」。

基岩版（手機）的朋友也能進嗎？

開放基岩版伺服器（19132 連接埠・UDP）後，手機和電腦上的基岩版玩家都能加入。Switch 等遊戲主機連線外部伺服器有限制。

Micle 可以免費使用

除了連接埠轉送，Micle 也能檢查防火牆規則、使用連接埠的應用程式和網路速度。
