Micle 使用指南

开始使用摩尔斯电码（发送・识别・练习）

Micle 可以把键盘按键或鼠标按钮当作电键使用。拍发的电码会显示为文字，也能以摩尔斯音的形式送进 Discord 等通话。还可以识别对方的摩尔斯电码，并提供听码练习。

需要准备

  • Micle（免费）
  • 在通话中使用时，需要设置 Discord 等（参见这里）

操作步骤

  1. 选择拍发方式

    在 Morse 页面的 Keys 标签中，选择 手键（一个键，按住长短区分点划）或 自动键（点和划用不同的键），并分配按键或鼠标按钮。

  2. 设置速度和音调

    在 Tone & Speed 标签中设置字符速度（WPM）和音高。建议从 12–15 WPM 开始。“Slower spacing only (Farnsworth)” 可以在保持字符速度的同时加大字符间隔。

  3. 试着拍发

    用分配的键拍发，时间轴会显示长短，“Decoding my keying”会显示文字。

  4. 输入文字发送

    在 Send 标签中输入文字，会自动转换成摩尔斯音发送。也支持 <AR> 等勤务符号。常用语可以存为固定短语，用 Ctrl + Alt + 1–8 发送。

  5. 练习听码

    Practice 标签会随机播放摩尔斯电码让你作答。每个字符的正确率用颜色显示，还能让薄弱字符多出现。

把对方的摩尔斯电码变成文字

Receive 标签会监听通话声音中的摩尔斯电码并转成文字。噪音导致误判时，调高“Detection strictness”。

游戏中也可以不出声，用摩尔斯电码悄悄打信号。

常见问题

支持日文摩尔斯电码吗？

支持。发送和识别都可以在国际码（A–Z）和日文假名之间切换。

可以用真正的电键吗？

只要设备是以键盘或鼠标输入的形式识别，就可以分配那个键来使用。
