把我的世界服务器开放给朋友（端口转发）

想让家外面的朋友加入你电脑上的我的世界服务器，需要“端口转发”。一般要进入路由器设置页操作，而用 Micle 只需一个按钮就能开放或关闭端口。

如果大家都在同一个家里（同一个 Wi-Fi），就不需要端口转发，用服务器电脑的局域网地址即可加入。

需要准备

  • 我的世界服务器（Java 版用官方 server.jar，基岩版用 Bedrock Dedicated Server 等）
  • Micle（免费）
  • 开启了 UPnP 的路由器（大多数家用路由器默认开启）

操作步骤

  1. 启动服务器并确认自己能进入

    先启动服务器，用同一台电脑上的我的世界通过 localhost 确认能进入。如果这里进不去，请先检查服务器设置。

  2. 打开 Micle 的“Network”

    在 Micle 左侧菜单中打开 Other → Network，按“Find router”。显示“Found”就准备好了。

  3. 从常用游戏中选择 Minecraft

    在“Add from common games…”中，Java 版选 Minecraft (Java) = 25565 端口・TCP，基岩版选 Minecraft (Bedrock) = 19132 端口・UDP。名称和端口会自动填入。

  4. 按“Open”

    显示“Open”就表示端口已开放。如果仍然无法连接，把同一行防火墙一栏的“Allow”也打开（Windows 会确认一次）。

  5. 把地址告诉朋友

    在“Addresses”一栏中按 External IP 旁边的“Copy”，连同端口号一起发给朋友，例如 203.0.113.5:25565。朋友在我的世界的“多人游戏”→“直接连接”中输入即可。

  6. 玩完后关闭

    不要一直开着更安全。打开“Close when Micle closes”，退出 Micle 时会自动关闭。

遇到问题时

  • 找不到路由器：路由器的 UPnP 可能被关闭了。请参照路由器说明书开启“UPnP”。
  • 已开放但朋友进不来：部分网络套餐不允许外部连接（CGNAT、仅 IPv6 等）。可以考虑运营商的固定 IP 服务，或 Minecraft Realms 等方式。
  • 提示“端口已被占用”，服务器无法启动：用 Micle 的“Apps using a port”查看是哪个应用在占用。
端口转发会让外部的人能连接到你的电脑。请为服务器启用白名单、保持最新版本，用完后关闭端口。

常见问题

端口转发危险吗？

外部只能访问在该端口运行的软件（我的世界服务器）。启用白名单并在用完后关闭，可以大大降低风险。

IP 地址每次都一样吗？

取决于你的网络套餐，重启路由器等情况下可能会变。朋友进不来时，请在 Micle 里重新确认“External IP”。

基岩版（手机）的朋友也能进吗？

开放基岩版服务器（19132 端口・UDP）后，手机和电脑上的基岩版玩家都可以加入。Switch 等游戏机连接外部服务器有限制。

Micle 可以免费使用

除了端口转发，Micle 还能检查防火墙规则、占用端口的应用和网络速度。
