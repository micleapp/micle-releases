Micle 사용 가이드

마인크래프트 서버를 친구에게 공개하기 (포트 포워딩)

내 PC에서 연 마인크래프트 서버에 집 밖의 친구가 들어오려면 "포트 포워딩"이 필요합니다. 보통은 공유기 설정 화면에 들어가서 조작하지만, Micle을 쓰면 버튼 하나로 열고 닫을 수 있습니다.

같은 집(같은 Wi-Fi)에 있는 사람끼리만 논다면 포트 포워딩은 필요 없습니다. 서버 PC의 내부 주소로 들어올 수 있습니다.

준비물

  • 마인크래프트 서버(자바는 공식 server.jar, 베드락은 Bedrock Dedicated Server 등)
  • Micle(무료)
  • UPnP가 켜진 공유기(대부분의 가정용 공유기는 처음부터 켜져 있습니다)

방법

  1. 서버를 열고 직접 들어가지는지 확인

    먼저 서버를 실행하고, 같은 PC의 마인크래프트에서 localhost로 들어가지는지 확인합니다. 여기서 안 되면 포트 포워딩 전에 서버 설정을 확인하세요.

  2. Micle의 "Network" 열기

    Micle 왼쪽 메뉴의 Other → Network를 열고 "Find router"를 누릅니다. "Found"가 나오면 준비 완료입니다.

  3. 자주 쓰는 게임에서 Minecraft 선택

    "Add from common games…"에서 자바는 Minecraft (Java) = 25565번·TCP, 베드락은 Minecraft (Bedrock) = 19132번·UDP를 고릅니다. 이름과 포트가 자동으로 들어갑니다.

  4. "Open" 누르기

    "Open"이 표시되면 포트 포워딩이 된 것입니다. 그래도 안 되면 같은 줄 방화벽 칸의 "Allow"도 켭니다(Windows 확인 창이 한 번 뜹니다).

  5. 친구에게 주소 알려 주기

    "Addresses" 칸의 External IP 옆 "Copy"를 눌러 포트 번호와 함께 친구에게 보냅니다. 예: 203.0.113.5:25565. 친구는 마인크래프트의 "멀티플레이" → "직접 연결"에 입력하면 됩니다.

  6. 다 놀았으면 닫기

    열어 둔 채로 두지 않는 것이 안전합니다. "Close when Micle closes"를 켜 두면 Micle을 끌 때 자동으로 닫힙니다.

잘 안 될 때

  • 공유기를 찾지 못함: 공유기 설정에서 UPnP가 꺼져 있을 수 있습니다. 공유기 설명서를 보고 "UPnP"를 켜 주세요.
  • 열렸는데 들어오지 못함: 인터넷 요금제에 따라 외부에서 들어올 수 없는 구조(CGNAT, IPv6 전용 등)일 수 있습니다. 통신사의 고정 IP 서비스나 Minecraft Realms 같은 방법을 검토해 보세요.
  • "포트가 사용 중"이라며 서버가 안 켜짐: Micle의 "Apps using a port"에서 어떤 앱이 쓰고 있는지 확인할 수 있습니다.
포트 포워딩은 외부 사람이 내 PC에 닿을 수 있게 하는 설정입니다. 서버는 화이트리스트를 쓰고, 최신 버전으로 유지하고, 다 쓰면 닫아 주세요.

자주 묻는 질문

포트 포워딩은 위험하지 않나요?

연 포트에서 동작하는 소프트웨어(마인크래프트 서버)에만 닿습니다. 화이트리스트를 쓰고 다 쓴 뒤 닫으면 위험을 크게 줄일 수 있습니다.

IP 주소는 항상 같나요?

요금제에 따라 공유기를 재시작할 때 등에 바뀔 수 있습니다. 친구가 못 들어오면 Micle에서 "External IP"를 다시 확인하세요.

베드락(모바일) 친구도 들어올 수 있나요?

베드락 서버(19132번·UDP)를 열면 모바일과 PC의 베드락 플레이어가 들어올 수 있습니다. Switch 등 콘솔은 외부 서버 접속에 제한이 있습니다.

Micle은 무료로 사용할 수 있습니다

포트 포워딩 말고도 방화벽 허용, 포트를 쓰는 앱, 연결 속도를 Micle 하나로 확인할 수 있습니다.
